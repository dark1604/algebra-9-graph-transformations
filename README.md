# Найпростіші перетворення графіків функцій (9 клас, Істер)

Інтерактивний веб-демонстратор та конспект уроку для вчителя математики за **§ 10 «Найпростіші перетворення графіків функцій»** підручника:
> О. Істер, Д. Істер. *Алгебра : підручник для 9 класу закладів загальної середньої освіти* (К.: Генеза, 2026).

## Можливості веб-додатка
- **Базові функції:** $y = x^2$, $y = \sqrt{x}$, $y = |x|$, $y = \frac{k_0}{x}$, $y = x^3$, $y = 0{,}5x - 2$, $y = x^2 - 4$.
- **Усі види перетворень із § 10:**
  - вертикальний зсув $y = f(x) \pm n$;
  - горизонтальний зсув $y = f(x \pm m)$;
  - симетрія відносно осі абсцис $y = -f(x)$;
  - розтяг та стиск уздовж осі ординат $y = kf(x)$ ($k > 0$);
  - побудова $y = |f(x)|$.
- **Покроковий режим вчителя (`Крок 0` → `Крок 4`):** почергова демонстрація етапів перетворення з проміжними графіками, стрілками переходу опорних точок і таблицею значень.
- **17 готових пресетів з підручника:** Приклади 1–8 та ключові вправи (№ 10.4, 10.7, 10.8, 10.12, 10.15, 10.19, 10.21*).
- **Інтерактивне полотно:** масштабування, перетягування координатної площини, асимптоти гіперболи та рухома пряма $y = a$ для графічного дослідження рівнянь.

## Структура проєкту
- `index.html` — інтерфейс демонстратора;
- `styles.css` — стилі для роботи на проєкторі та інтерактивній дошці;
- `app.js` — математична модель і рендеринг графіків на HTML5 Canvas;
- `conspectus-10-peretvorennia-grafikiv.md` — повний конспект уроку для вчителя.
